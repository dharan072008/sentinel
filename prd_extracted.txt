1. Product Overview
SENTINEL is a context-aware surveillance intelligence prototype designed for complex border environments where surveillance cannot rely only on fences, predefined restricted zones, or simple object detection. It analyzes ordinary CCTV footage and progressively converts raw video into contextual intelligence: SEE → IDENTIFY → TRACK → LOCATE → UNDERSTAND → LEARN NORMAL → DETECT DEVIATION → CORRELATE → CONTEXTUALIZE → EXPLAIN.
2. Problem Statement
Border regions can contain villages, roads, houses, farms, civilians, animals, birds, vehicles and changing environmental conditions. Basic CCTV analytics may report that a person, bird or vehicle is present, or that a person entered a zone, but these signals alone may not explain whether the activity is ordinary or unusual.
SENTINEL combines object detection, tracking, spatial intelligence, observable behaviour analysis, behavioural baselines, odd-one-out detection, event-sequence reasoning, bird/drone intelligence, ecological context, multi-sensor evidence and explainable alerts.
3. Prototype Objective
The prototype must allow a user to upload a CCTV video and watch the system analyze it while it plays.
Required flow: Upload CCTV → Play Video → Detect Objects → Track Frame-by-Frame → Spatial Intelligence → Human Behaviour Analysis → Behavioural Baseline → Baseline Comparison → Odd-One-Out → Event Sequence → Bird/Drone Intelligence → Context/Sensor Simulation → Evidence Fusion → Explainable Alert → Final Dashboard.
4. Product Vision
Traditional surveillance asks: 'What is there?' SENTINEL asks: 'What is there, what is it doing, is that normal here, and what evidence makes it unusual?'
5. Target Users
Surveillance operator — monitors video, tracks entities and reviews alerts.
Security analyst/supervisor — investigates unusual activity and reviews supporting evidence.
6. System Inputs
Primary input: uploaded CCTV video.
Optional context: region, location, date, time, season, environment type and virtual zones.
Future sensor inputs: thermal camera, radar, acoustic sensors and environmental sensors.
Prototype sensor rule: CCTV is the real input; unavailable sensors may be simulated and must be visibly labelled as simulated.

13. Restricted-Area Intelligence
For people and other tracked entities, the system checks whether they enter defined restricted areas.
Example: Person P07 → Road → Restricted Area → Exit.
A restricted-area event becomes one evidence signal. It should not automatically be presented as proof of malicious intent.

15. Person–Object Interaction
The original bag concept is implemented as a general person-object event sequence rather than a fixed threat rule.
Person approaches an object.
Person interacts with the object.
Object is placed or left.
Person moves away.
Object remains.
The sequence is recorded and evaluated alongside other evidence and the behavioural baseline.
16. Other Behavioural Sequence Patterns
Route deviation: normal route → unexpected turn → sensitive/restricted proximity.
Unusual dwell: arrival → stop → unusually long stay → departure.
Repeated movement: location A → B → A → B.
Group separation: group movement → one individual separates → different route → later rejoin.
These are observable patterns for anomaly analysis, not automatic proof of threat.

19. Odd-One-Out Intelligence
SENTINEL performs population-level comparison to identify entities that behave significantly differently from surrounding activity.
Example: 40 people → 37 consistent with baseline → 2 moderate deviations → 1 significant outlier.
The output is a behavioural outlier for review, not a declaration that the person is a criminal or threat.
20. Event Sequence Intelligence
Separate events are connected chronologically so operators can understand the whole sequence instead of receiving unrelated alerts.
Example: Detection → route deviation → restricted-area entry → unusual dwell → object interaction → exit.
21. Bird / Drone Intelligence
Aerial objects follow a dedicated analysis path. The system first tracks the object and evaluates whether its evidence is more consistent with a bird, drone or unknown aerial object.
Bird-like path: Visual analysis → Thermal evidence → Species identification → Region → Season → Time → Habitat → Ecological consistency.
22. Thermal Intelligence
Thermal data can provide an additional evidence source for aerial classification.
Real thermal camera input in a future production deployment.
Simulated thermal input for the prototype when hardware is unavailable.
The dashboard must clearly label simulated thermal information.
23. Bird Species Intelligence
When visual information is sufficient, the system estimates a likely species and confidence. If evidence is insufficient, it should return Unknown/Low Confidence rather than forcing a classification.
24. Ecological Context Intelligence
The system checks whether the identified or suspected bird is ecologically consistent with the observed context.
Region — expected in this geographical area?
Season — expected during this season?
Time of day — consistent with normal observation/activity?
Habitat — consistent with the surrounding environment?
25. Bird vs Drone Reasoning
The system combines visual appearance, movement, thermal evidence, species confidence and ecological context.
If evidence agrees, confidence increases. If evidence conflicts, the system reports an ambiguous aerial object and recommends human review.

27. Multi-Sensor Architecture
Production architecture should allow independent evidence sources to be added without redesigning the intelligence layer.
CCTV + Thermal + Radar + Acoustic + Environmental → Evidence Fusion.
For the prototype, only CCTV needs to be genuinely connected. Other signals can be simulated to demonstrate the architecture.
28. Evidence Fusion
SENTINEL combines visual, tracking, spatial, behaviour, baseline, ecological, thermal and future sensor evidence.
The system should preserve the contribution of each evidence source so that the final alert remains explainable.
29. Contradiction Engine
The contradiction engine detects situations where evidence sources disagree.
Example: Visual = bird-like, thermal = inconsistent, ecological context = unusual, movement = unusual → Evidence conflict → Human review.
The system should prefer uncertainty over a forced classification when evidence is insufficient or contradictory.
30. Priority Engine
The priority engine combines multiple signals to determine which events deserve operator attention.

The resulting priority is an operational review priority, not a prediction of criminality.
31. Explainable Intelligence
Every important alert must answer:
What happened?
Where did it happen?
When did it happen?
Why was it unusual?
What evidence contributed?
Example: Behavioural Outlier — P07 — restricted-area entry, route deviation, unusual dwell and object-interaction sequence — high review priority — human review recommended.

33. Example Final Dashboard Event
Person P07 is detected in a village CCTV scene. The system tracks P07 across frames. P07 moves away from the common route, approaches a restricted area, remains longer than the local baseline, interacts with an object and leaves. SENTINEL does not simply label the person a threat. It presents the sequence as a significant behavioural outlier with the individual evidence signals visible to the operator.
34. Example Aerial Event
Aerial object B04 is detected and tracked. The object appears bird-like. The system evaluates simulated/real thermal evidence, estimates a species where possible, then checks whether that species is expected in the region, season, time and habitat. If evidence is consistent, the system reports high ecological consistency. If evidence conflicts, it reports an ambiguous aerial object and requests human review.

40. Accuracy and Human Oversight
SENTINEL is a decision-support system. Detection, anomaly and outlier results are evidence for review, not automatic conclusions about a person's intent or criminality.
The system must expose uncertainty, confidence and evidence conflicts and provide a human-review step.

42. Product Differentiation
SENTINEL's differentiation is the transition from simple object detection to contextual behavioural intelligence.
Instead of treating every detected object as a possible threat, the system establishes environmental context, learns what is normal, detects significant deviations, correlates events and explains the evidence.
43. Final Product Definition
SENTINEL is a context-aware surveillance intelligence platform that turns ordinary CCTV footage into an adaptive understanding of people, objects and environmental activity—tracking what is present, understanding how it moves, learning what is normal for that location and context, identifying meaningful outliers, contextualizing bird/aerial activity, and providing explainable evidence for human review.
